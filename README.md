# 🐍 Snake Game Android App

A classic **Snake Game Android Application** developed using **Java and XML** in Android Studio.

This project provides a smooth gaming experience with simple controls, score tracking, and interactive gameplay.

---

## 📱 About The Project

Snake Game is an Android-based game where the player controls a snake, collects food, and increases the score.

The snake grows longer after eating food, and the player needs to avoid collision with walls and the snake's own body.

---

## ✨ Features

- 🐍 Classic Snake Gameplay
- 🎮 Touch-based Controls
- 🍎 Random Food Generation
- 📊 Real-Time Score Tracking
- 💀 Game Over Detection
- 🔄 Restart Game Option
- ⚡ Smooth Animation
- 📱 Android Mobile Support

## 🎯 How To Play

1. Open the Snake Game app.
2. Control the snake using touch controls.
3. Collect food 🍎 to increase your score.
4. Avoid hitting the walls and your own body.
5. Try to achieve the highest score!
